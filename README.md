# Homebrew Tap

Homebrew formulae and casks for Illegal Studio projects.

## Usage

```bash
brew tap illegalstudio/tap
brew install <formula>
brew install --cask <cask>
```

## Formulae

| Formula | Description |
|---------|-------------|
| `codejournal-cli` | Project memory and work history for developers and coding agents |
| `context` | Deterministic, explainable context packs for coding tasks |
| `darkbox` | Offline inspection and verification of Darkbox project archives |
| `elephc` | PHP-to-native compiler targeting macOS ARM64 |
| `ggg` | Clone and manage Git repositories from a YAML configuration file |
| `ggw` | Ergonomic Git worktree manager with predictable shared worktree storage |
| `lazyagent-cli` | Lazy TUI for monitoring coding agent sessions |
| `pxon` | CLI for managing Proxmox VE LXC containers |

## Casks

| Cask | Description |
|------|-------------|
| `lazyagent` | Desktop app for monitoring coding agent sessions (includes the CLI) |
| `mnemo` | Local-first desktop app to archive and search your AI chat conversations |
